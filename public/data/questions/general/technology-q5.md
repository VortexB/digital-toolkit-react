# The technology needs to be installed across multiple technical systems

## Recommended Actions
1. Assess whether integration between multiple systems is really necessary or if there are ways to avoid or delay this during initial testing.
2. Consult with the IT departments of each institution to identify, negotiate and resolve infrastructural conflicts (e.g., lack of accessibility or hindering requirements).
3. Understand the concept of interoperability and how it can improve patient experience.
