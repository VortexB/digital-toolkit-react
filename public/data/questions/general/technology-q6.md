# There is a need to upgrade/change the organization's IT system for implementing (e.g., new hardware, better bandwidth).

## Recommended Actions
1. Reassess whether it is really necessary to have the IT system upgraded or changed, or if there are ways to avoid or delay this during initial testing.
2. If upgrading is necessary, estimate operational costs (ongoing recurrent costs for upgrading and maintaining the system) to assess feasibility and sustainability.
