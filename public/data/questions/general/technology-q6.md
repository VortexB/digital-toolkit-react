# Domain 1: There is a need to upgrade/change the organization’s IT system for implementing (e.g., new hardware, better bandwidth).

## Recommended Actions
1. Reassess whether it is really necessary to have the IT systemupgraded or changed, or if there are ways to avoid or delay this duringinitial testing.
2. If upgrading is necessary, estimate operational costs (ongoing recurrentcosts for upgrading and maintaining the system) to assess feasibilityand sustainability.
